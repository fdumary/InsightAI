## Description
A web app where a user uploads a CSV of customer messages, the AI instantly returns: Categories (Billing, Support, Sales), Sentiment (Positive, Neutral, Negative), Urgency (High, Medium, Low) and the summary of customer service.
## Technologies
We built it using Vite, and Tailwind CSS and lucid-react.
## Setup
Navigate to frontend/ dir and run ```npm run dev```
